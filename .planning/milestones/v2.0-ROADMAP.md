# Milestone v2.0: Personalized Action & Decision Intelligence

**Status:** ✅ SHIPPED 2026-03-22
**Phases:** 30-39
**Total Plans:** 30

## Overview

This archive captures the milestone that turned Credit Coach from a portfolio-proven recourse and productization stack into a personalized action-intelligence system. The work replaced feature-native recommendation language with deterministic semantic actions, customer-specific numeric targets, explicit feasibility and execution realism, institution-side offer truth, cleaner product narratives, typed product-surface consumption, portfolio-level numeric impact and calibration review, and a pilot-facing package seam built on the same engine-owned truth.

## Phases

### Phase 30: Action Semantics Hardening

**Goal**: Turn feature deltas into a stable real-world action mapping layer that is deterministic, typed, and product-safe.
**Depends on**: Phase 25
**Plans**: 3 plans

- [x] 30-01: Build a deterministic action catalog with canonical families and fail-closed feature mapping

## Milestone Summary

**Key Decisions:**
- Personalized action intelligence had to be built as a layered contract stack: semantics, numeric targets, feasibility, execution, offers, narratives, surfaces, portfolio proof, calibration, and pilot packaging.
- The Python engine remained the single source of truth, and the website consumed typed artifacts instead of inventing UI-side decision logic.
- Portfolio proof stayed more honest than impressive by emphasizing execution-aware payoff, calibration, and offer dependency instead of nominal uplift alone.
- Pilot integration stayed export-first and controlled rather than pretending live institution connectivity already existed.

**Issues Resolved:**
- Raw feature-delta recommendation language is no longer the default visible plan contract.
- Personalized plans are now numeric, feasibility-aware, execution-aware, and offer-aware instead of stopping at semantic action labels.
- Product surfaces now read the same engine-owned personalized truth they expose to buyers and analysts.
- Portfolio proof can now quantify both numeric impact and validation honesty across the cohort.
- A pilot-facing package seam now exists without forking the planner into a separate integration-only path.

**Issues Deferred:**
- Pilot-grade external institution integrations remain future work beyond the shipped export and package contract.
- Regulatory explanation and adverse-action communication packs remain outside this milestone.
- Recurring automation for proof refresh, release review, and milestone health remains future scope.

**Technical Debt Incurred:**
- The local `gsd-tools.cjs` helper still cannot initialize `milestone-op`, so some milestone workflows require manual fallback.
