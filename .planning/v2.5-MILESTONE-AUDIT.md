# v2.5 Milestone Audit — Recoverable Customer Targeting & Movement Optimization

## 1. Summary Verdict

**Verdict:** v2.5 is a **capability-expansion + targeting-optimization milestone**, and it is now in an **audit-passed / archivable** state for its **core scope (Phases 61–66)**.

What is **clearly achieved** in code and artifacts:
- Deterministic recoverability signal + conservative recoverable classifier
- Honest routing: **full** mode only when recoverable; **limited** mode is explicitly informational and empty-state-safe
- Movement-aware ranking for recoverable/full customers that prioritizes threshold reachability
- Targeted cohort evaluation surfaces (recoverable/full vs global denied; limited mode as honesty control) with explicit non-uplift posture
- Narrative posture contract (`actionable` vs `informational`) that is drift-checked across producer/consumer surfaces

What is **not yet proven**:
- **Business lift** (or even stable cohort-level movement concentration) on a sufficiently sized, real denied population
- Large-sample evidence of movement concentration (the capability exists; the evidence in this audit remains deliberately small and non-claims-based)

## 6. Limitations (Must Be Explicit)

- **Movement remains low in the small evidence run**: movement and strong movement rates were 0.0, and `threshold_reach_possible_rate` was 0.0.
- **Targeting concentration is not yet demonstrated**: the targeted comparison framework exists, but the evidence run had **no recoverable** customers; a full_processed cohort run is required.
- **Structural limitation dominates in the small evidence run**: `recoverability_bucket_distribution` skewed heavily toward `structural_limited`.
- **Outcome realization (Phase 67) is non-core**: it is implemented, but v2.5’s audit-pass decision is based on core milestone scope (61–66). If Phase 67 is to be treated as first-class deliverable, add a formal `67-VERIFICATION.md`.

## 7. Top 5 Insights

1. The v2.5 system is now capable of being **honest by construction**: limited mode is not “weaker advice”; it is an explicit *no-promotion* posture with empty-state-safe surfaces.
2. “Near threshold” is not equivalent to “recoverable”: the classifier requires path evidence + blocker checks, preventing fake actionability.
3. Movement ranking is implemented as a **gated branch** (recoverable/full-only), reducing the chance of broad behavioral drift.
4. Narrative integrity is treated as a first-class constraint: posture fields are producer-owned, surfaced in operator/external artifacts, and consumed by the demo with explicit assertions.
5. The missing piece is not more capability—it is **evidence at scale** on real denied populations (and, optionally, a formal verification report for Phase 67 if that layer is promoted into core scope).

**Milestone classification:** capability-expansion + targeting-optimization milestone

**Not yet:** business-lift milestone
