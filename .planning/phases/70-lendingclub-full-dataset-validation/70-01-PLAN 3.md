<task type="auto">
  <name>Task 2: Prepare the full dataset (CSV → parquet) under the Phase 70 processed roots</name>
  <files>credit-coach/data/processed_lendingclub_full/*, credit-coach/data/splits_lendingclub_full/*</files>
  <action>
First, run a **fail-fast schema preflight** (LCFULL-02) and write a schema report JSON to:
- `data/splits_lendingclub_full/ingest_schema_report.json`

Schema report requirements (descriptive, not optimization):
- record `raw_columns` from the raw CSV header
- record `required_columns` from `configs/features_48.yaml` (`features` + `target`)
- record `kept_columns` (intersection of raw with required)
- record `dropped_extra_columns` (raw minus required)
- record `missing_required_columns` (required minus raw)

Recommended command:
`cd credit-coach && PYTHONPATH=src python3 -c "import json, pathlib, pandas as pd, sys; from credit_coach.data.ingest import load_feature_contract; cfg_path=pathlib.Path('configs/lendingclub_full.yaml'); cfg=__import__('credit_coach.utils.run_context', fromlist=['load_config']).load_config(cfg_path); raw=str(cfg.get('paths',{}).get('raw_csv','')); contract=load_feature_contract(pathlib.Path(cfg.get('features_config','configs/features_48.yaml'))); required=list(contract['features'])+[contract['target']]; raw_cols=list(pd.read_csv(raw, nrows=0).columns); kept=[c for c in required if c in raw_cols]; dropped=[c for c in raw_cols if c not in required]; missing=[c for c in required if c not in raw_cols]; out={'raw_csv':raw,'raw_columns':raw_cols,'required_columns':required,'kept_columns':kept,'dropped_extra_columns':dropped,'missing_required_columns':missing}; pathlib.Path('data/splits_lendingclub_full').mkdir(parents=True, exist_ok=True); pathlib.Path('data/splits_lendingclub_full/ingest_schema_report.json').write_text(json.dumps(out, indent=2), encoding='utf-8'); print('wrote ingest_schema_report.json'); sys.exit(1 if missing else 0)"`

Fail-fast rule (LCFULL-02):
- If `missing_required_columns` is non-empty, stop Phase 70 immediately (schema incompatibility).

Only after the schema preflight passes, run the canonical prepare-data CLI with the Phase 70 config:

`cd credit-coach && PYTHONPATH=src python3 -m credit_coach.cli.run_prepare_data --config configs/lendingclub_full.yaml`

Confirm outputs:
- `data/processed_lendingclub_full/train.parquet`
- `data/processed_lendingclub_full/test.parquet`
- `data/splits_lendingclub_full/split_summary.json`

If this fails due to memory, treat it as a Phase 70 compatibility failure and stop; do not silently reduce scale.
  </action>
  <verify>cd credit-coach && test -f data/splits_lendingclub_full/ingest_schema_report.json && python3 -c "import json; p='data/splits_lendingclub_full/ingest_schema_report.json'; d=json.load(open(p,'r',encoding='utf-8')); assert 'missing_required_columns' in d, d; assert d['missing_required_columns']==[], d" && test -f data/processed_lendingclub_full/train.parquet && test -f data/processed_lendingclub_full/test.parquet && python3 -c "import json; p='data/splits_lendingclub_full/split_summary.json'; d=json.load(open(p,'r',encoding='utf-8')); assert int(d.get('feature_count',-1))==48, d" && PYTHONPATH=src python3 -m pytest -q</verify>
